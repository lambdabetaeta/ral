ral

Running a command is an algebraic effect.

A Unix shell where the operation and its interpretation are separate things.

README.md

The command is an operation. The operating system is its default interpretation. Separate them, and typed commands, scoped authority, and a sandbox all fall out of a single principle — without giving up first-class commands and pipes.

ral refuses the shell collapse between data and source text. Values are inert; commands are effectful. Two sigils, no ambiguity: $ retrieves data, ! runs stored commands.

Not POSIX. No word splitting, no glob expansion on unquoted variables, no $IFS, no context-dependent quoting.

# no authority boundary —
# ssh can run anything, anywhere
cfg=$(curl -s "$api")
hosts=$(echo "$cfg" | jq -r '.hosts[]')
for h in $hosts; do      # word-split on IFS
    ssh "$h" 'systemctl restart app'
done

let cfg = curl -s $api | from-json
for $cfg[hosts] { |h|         # typed; no word split
    grant [exec: [ssh: []]] { # only ssh may run
        ssh $h 'systemctl restart app'
    }
}
